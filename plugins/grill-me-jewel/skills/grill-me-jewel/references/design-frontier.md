# Jewelry Design Frontier

Ask only the decisions that remain unresolved. Stop as soon as the answers support a coherent brief.

## Decision Order

1. **Starting point:** pure idea, gemstone, existing jewelry, sketch, story, or visual reference.
2. **Product identity:** ring, bracelet, necklace, pendant, earrings, brooch, set, or custom type.
3. **Design system:** gold-led, gemstone-set, mixed material, or another clearly named system.
4. **Meaning and motif:** emotion, occasion, recipient, story, symbol, cultural or natural subject.
5. **Form and style:** silhouette, visual weight, symmetry, movement, historical or contemporary mood.
6. **Materials and craft:** only facts the user cares about; leave undecided production details open.
7. **Output intent:** single design image, multiple independent design directions, campaign/display
   idea, model try-on intent, or another clearly named visual handoff.

## Routing Rules

- Explicit Grill Me requests always qualify, even when the user already knows one or two facts.
- An otherwise clear request such as “design a platinum sapphire ring” does not need a deep
  interview unless the user asks for one.
- Ask source-role questions only when an attachment exists or the chosen direction requires one.
- Preserve an explicit delivery count. When none is supplied, use one image as a reversible default
  and include it in the final confirmation instead of adding an unnecessary interview round.
- Do not turn optional taste choices into blockers. Label tasteful defaults as flexible details.

## Final Brief Quality

The brief must distinguish locked facts from flexible details, avoid invented gem or brand claims,
and be understandable without this plugin. It must be precise enough to compile into a professional
gpt-image-2 jewelry prompt without guessing product identity.

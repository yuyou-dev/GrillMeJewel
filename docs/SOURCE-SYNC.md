# Reviewed Source Baseline

The 0.3.0 creative guidance was adapted from reviewed source revision `3ff82ac655e329e55b9328a15c4d342adf68305e`.
This is provenance, not an installation or runtime dependency. This repository remains standalone.

| Source guidance | Public adaptation |
| --- | --- |
| Grill Me interview and design frontier | Adaptive/full modes, beginner-readable decisions, meaning translated into form, complete brief handoff |
| Ordinary jewelry design | Exact image versus piece/pair counts, locked category, selected-candidate refinement, honest delivery status |
| Professional image prompting | Seven-layer prompt order and design/presentation reference authority in `image2-generation.md` |
| White studio presentation and design presets | Self-contained references under the one public Skill, with local relative links |

The public Skill keeps its own `ask_grill_me_questions` tool, sequential rounds, final confirmation,
and Codex built-in image generation route. Shared multi-Skill routing and repository task-document
conventions are adapted to this single-Skill product. No new MCP tools or UI resources are added.

Internal runners, integrations, research notes, local paths, private task records, and designer media
are excluded. Model labels and platform-specific output controls are not imported. The package
makes no claim that prompt changes guarantee image quality or an exact output resolution.
